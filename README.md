Old Free Fire 2018 — Fan Tribute Website
A responsive, static nostalgia website made with HTML, CSS and vanilla JavaScript. It includes a hero section, 2018-era tribute copy, memory cards, original SVG artwork, a gallery, mobile navigation and a copy-caption button.
Files
index.html — page structure
style.css — responsive design and visual styling
script.js — mobile menu and copy-caption interaction
assets/ — original SVG illustrations and favicon
Run locally
Open index.html in a browser. No build tools or server are required.
Publish with GitHub Pages
Create a public GitHub repository, for example old-free-fire-2018.
Upload all files and the complete assets folder, keeping the same folder structure.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select branch main and folder / (root), then save.
Wait for GitHub Pages to publish. Your site URL will be https://YOUR-USERNAME.github.io/old-free-fire-2018/.
Customize
Replace the SVG files in assets/ with your own artwork if you want. Keep the filenames the same, or update the matching image paths in index.html and style.css.
